How to install the app and use it offline

Chrome or Edge: the Install the app button above, or the install icon at the right of the address bar. Safari on a Mac: File → Add to Dock. iPhone or iPad: Share → Add to Home Screen. Android: the browser menu → Install app. Once installed, open it from your Dock, Start menu or home screen. The first visit downloads R (about 100 MB) once; later updates download only what changed.

When you are online, the app checks for a newer version each time you open it. Every lab page has a bar at the top: All weeks brings you back here.

How a lab page works

Press Run Code on a cell; change the code and run it again (you cannot break anything). The first cell loads the data by itself. The tasks have the same numbers as your R handout (R 7.1, R 7.2, ...). Pick your tier under "Your tier": Core, Applied or Challenge (and a Stretch task if you finish early). Each tier task has a Hint; the answers are at the end of your R handout (Part 2 of the Week Pack): try first.

RStudio on your laptop is the main way to do the labs and the R handout. This app runs the same R and gives the same numbers.
