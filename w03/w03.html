Core. For 20 resort bookings, find \(P(8 \text{ or more cancel})\). Then find \(P(\text{exactly } 10)\) of 20 city bookings cancel.

TipHint

find p_res as in R 3.1 with "Resort Hotel"; then 1 - pbinom(7, 20, p_res) and dbinom(10, 20, p).

NoteAnswer (try first)

Core. Resort \(p = 0.281\); \(P(X \ge 8) = 0.173\), against 0.661 for the city. City \(P(X = 10) = 0.138\).

p_res <- mean(hotels$is_canceled[hotels$hotel == "Resort Hotel"])
1 - pbinom(7, 20, p_res)
p <- mean(hotels$is_canceled[hotels$hotel == "City Hotel"])
dbinom(10, 20, p)

Applied. Is a Poisson model good for special requests? Compare the model with the data (R 3.4), then find \(P(3 \text{ or more requests})\) both ways.

TipHint

1 - ppois(2, lam) and mean(hotels$total_of_special_requests >= 3).

NoteAnswer (try first)

Applied. \(\lambda = 0.571\). \(P(\ge 3)\): model 0.020, data 0.024. The model is close; the data have a few more bookings with no request (0.589 against 0.565). Good enough for planning.

lam <- mean(hotels$total_of_special_requests)
round(dpois(0:4, lam), 3)                                     # model
data_share <- numeric(5)
for (k in 0:4) {
  data_share[k + 1] <- mean(hotels$total_of_special_requests == k)
}
round(data_share, 3)                                          # data
1 - ppois(2, lam)
mean(hotels$total_of_special_requests >= 3)

Challenge. Fit a normal model to city room rates (R 3.5). Find \(P(\text{rate} > \text{€}150)\) and the 90th percentile both ways. Then compare \(P(\text{rate} < \text{€}40)\): where does the model miss?

Start from this:

TipHint

pnorm(40, m, s) and mean(rate < 40).

NoteAnswer (try first)

Challenge. \(P(> \text{€}150)\): model 0.124, data 0.118. 90th percentile: model €154.78, data €157.00. \(P(< \text{€}40)\): model 0.037, data 0.004: the model fits the middle but not the left tail, and it allows negative rates.

rate <- hotels$adr[hotels$hotel == "City Hotel"]
m <- mean(rate)
s <- sd(rate)
1 - pnorm(150, m, s)
mean(rate > 150)
qnorm(0.9, m, s)
quantile(rate, 0.9)
pnorm(40, m, s)
mean(rate < 40)

Stretch (any tier, if you finish early). Approximate \(P(8 \text{ or more of 20 city bookings cancel})\) with a normal curve that has the binomial’s mean and SD. Start “8 or more” at 7.5 (the continuity correction). How close is it to the exact answer?

NoteAnswer (try first)

Stretch. 1 - pnorm(7.5, 20 * p, sqrt(20 * p * (1 - p))) \(= 0.665\), against the exact 0.661. Without the correction (8 instead of 7.5): 0.579, much further off.

R 3.7 · Simulate to check: the board, and real nights (block 5)

NoteYou should see

Bookings drawn at random behave like the binomial. If the 20 rooms are 4 blocks of 5 that cancel together, the chance changes and the spread is more than twice as wide. Check independence before you trust a binomial.

Commands to know

These can be assessed in the quiz, because this week’s R tasks run them: dbinom, pbinom, qbinom, rbinom (binomial), dpois, ppois (Poisson), pnorm, qnorm (normal). The other members of each family (qpois, rpois, dnorm, rnorm) follow the same d, p, q, r pattern and are not asked. Remember: “at least \(k\)” is 1 - pbinom(k - 1, n, p); “more than \(x\)” is 1 - pnorm(x, m, s).
