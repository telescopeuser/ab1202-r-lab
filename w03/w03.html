Commands to know

These can be assessed in the quiz, because this week’s R tasks run them: dbinom, pbinom, qbinom, rbinom (binomial), dpois, ppois, qpois, rpois (Poisson), dnorm, pnorm, qnorm, rnorm (normal). One pattern for every family: d the chance of exactly k (for the normal, the curve’s height), p the chance of k or fewer (below x), q the value with a given chance below it, r random draws. Remember: “at least \(k\)” is 1 - pbinom(k - 1, n, p); “more than \(x\)” is 1 - pnorm(x, m, s).
