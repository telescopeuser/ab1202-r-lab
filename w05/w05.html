Part 2 · Your tier

Core

Find \(r\) for lead time and cancelling, and the cancellation share in each lead-time band. Then find \(r\) for the resort only.

The lead-time column is lead_time.

cor(hotels$lead_time, hotels$is_canceled)                       # 0.291
lower <- c(0, 8, 31, 91, 181, 366)
upper <- c(7, 30, 90, 180, 365, 100000)
share_cancelled <- numeric(6)
for (b in 1:6) {
  in_band <- hotels$lead_time >= lower[b] & hotels$lead_time <= upper[b]
  share_cancelled[b] <- mean(hotels$is_canceled[in_band])
}
round(share_cancelled, 3)                                       # from 0.097 to 0.680
resort <- hotels[hotels$hotel == "Resort Hotel", ]
cor(resort$lead_time, resort$is_canceled)                       # 0.228

Applied

Build the joint table of special requests (0, 1, 2 or more) and cancelling. Find \(P(\text{cancelled})\), \(P(\text{cancelled} \mid 2 \text{ or more})\) and the covariance, by hand from the table and with cov().

The cancellation column is is_canceled. For the covariance by hand: \(E(XY) - E(X)E(Y)\), with \(E(XY) = 1 \times P(1, 1) + 2 \times P(2, 1)\).

req <- hotels$total_of_special_requests
req[req > 2] <- 2
n <- nrow(hotels)
requests <- c(0, 1, 2)
p_stayed <- numeric(3)
p_cancelled <- numeric(3)
for (i in 1:3) {
  p_stayed[i]    <- sum(req == requests[i] & hotels$is_canceled == 0) / n
  p_cancelled[i] <- sum(req == requests[i] & hotels$is_canceled == 1) / n
}
sum(p_cancelled)                                    # P(cancelled) = 0.375
p_cancelled[3] / (p_stayed[3] + p_cancelled[3])     # 0.214
cov(req, hotels$is_canceled)                        # -0.085; by hand 0.119 - 0.544 x 0.375

Challenge

Is the lead-time link the same in every market segment? Find \(r\) inside each segment, and for bookings with no deposit. What does that say about cause?

The deposit type with no money up front is written "No Deposit".

segments <- c("Online TA", "Offline TA/TO", "Groups", "Direct", "Corporate")
for (s in segments) {
  rows <- hotels$market_segment == s
  r <- cor(hotels$lead_time[rows], hotels$is_canceled[rows])
  print(paste(s, ": r =", round(r, 3)))
}
nd <- hotels$deposit_type == "No Deposit"
cor(hotels$lead_time[nd], hotels$is_canceled[nd])      # 0.149

Positive in every segment (0.22, 0.20, 0.28, 0.12, 0.29), smaller without deposits. Segment is not the whole story, but observed data still cannot prove that booking early causes cancelling.
