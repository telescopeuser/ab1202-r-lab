How to use this lab

RStudio is the main way to do the lab (the R handout in your Week Pack and the R Recipes file). This page is the alternative when RStudio is not available: it runs R in your browser (webR), with nothing to install. The code is the same, starting with the same first line, hotels <- read.csv("hotels.csv").

  • Press Run Code on each cell. Change the code and run it again; you cannot break anything.
  • Step 1 is always the same line: hotels <- read.csv("hotels.csv"). On this page it runs by itself when the page opens; wait for the first cell to show the size of the data.
  • Pick your tier in Part 2: Core, Applied or Challenge. Same data, same idea, different depth.

Part 2 · Your tier

Core

lm(adr ~ guests): the slope, intercept and \(R^2\). Predict the rate for 2 and for 4 guests.

The second prediction is for 4 guests.

m1 <- lm(adr ~ guests, data = hotels)
coef(m1)                                   # 40.46 and 32.08
summary(m1)$r.squared                      # 0.191
predict(m1, data.frame(guests = c(2, 4)))  # 104.61 and 168.76

Applied

Add the hotel and summer dummies. Interpret each coefficient, then quote 3 guests at the resort in August.

August is in summer: summer = TRUE.

m3 <- lm(adr ~ guests + hotel + summer, data = hotels)
round(coef(m3), 2)   # guests 28.14, resort -11.99, summer 33.19, each holding the others fixed
predict(m3, data.frame(guests = 3, hotel = "Resort Hotel", summer = TRUE))   # 150.41
