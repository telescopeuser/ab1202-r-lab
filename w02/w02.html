Part 2 · Your tier

Core

Find \(P(C \mid \text{Resort})\). Then compare first-time guests (is_repeated_guest = 0) with returning guests (1).

The column for returning guests is called is_repeated_guest.

mean(hotels$is_canceled[hotels$hotel == "Resort Hotel"])   # 0.281
mean(hotels$is_canceled[hotels$is_repeated_guest == 0])     # first stay 0.381
mean(hotels$is_canceled[hotels$is_repeated_guest == 1])     # returning 0.162

Returning guests cancel far less: about one in six, against more than one in three.

Applied

Are hotel and cancellation independent? Check \(P(C \mid \text{City})\) against \(P(C)\), and \(P(\text{City and } C)\) against \(P(\text{City})P(C)\). Then compare bookings with and without a special request.

“At least one special request” means more than 0.

city <- hotels$hotel == "City Hotel"
canc <- hotels$is_canceled == 1
mean(canc[city])          # 0.422
mean(canc)                # 0.375: not equal
mean(city & canc)         # 0.281
mean(city) * mean(canc)   # 0.249: not equal
has_request <- hotels$total_of_special_requests > 0
mean(hotels$is_canceled[has_request])    # 0.220
mean(hotels$is_canceled[!has_request])   # 0.483

Not independent. Bookings with a special request cancel less than half as often; a request is a sign the guest plans to come (it does not make them come).

Challenge

Find \(P(\text{non-refundable} \mid C)\) by Bayes’ rule and by counting. Then find out who the non-refundable bookings are: which hotel, which market segment, how far ahead.

p_nr <- mean(hotels$deposit_type == "Non Refund")
p_c_given_nr <- mean(hotels$is_canceled[hotels$deposit_type == "Non Refund"])
p_c_given_nr * p_nr / mean(hotels$is_canceled)                     # 0.329
mean(hotels$deposit_type[hotels$is_canceled == 1] == "Non Refund")  # 0.329, counted
nr <- hotels[hotels$deposit_type == "Non Refund", ]
mean(nr$hotel == "City Hotel")                                      # 0.882
segments <- sort(unique(nr$market_segment))
for (s in segments) {
  print(paste(s, round(mean(nr$market_segment == s), 3)))           # mostly groups and offline agents
}
mean(hotels$lead_time[hotels$deposit_type == "Non Refund"])         # 213 days
mean(hotels$lead_time[hotels$deposit_type == "No Deposit"])         # 90 days

Mostly city-hotel blocks booked through groups and agents, far ahead. Not evidence that deposits cause cancellations.
