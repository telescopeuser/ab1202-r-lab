How to use this lab

RStudio is the main way to do the lab (the R handout in your Week Pack and the R Recipes file). This page is the alternative when RStudio is not available: it runs R in your browser (webR), with nothing to install. The code is the same, starting with the same first line, hotels <- read.csv("hotels.csv").

  • Press Run Code on each cell. Change the code and run it again; you cannot break anything.
  • Step 1 is always the same line: hotels <- read.csv("hotels.csv"). On this page it runs by itself when the page opens; wait for the first cell to show the size of the data.
  • The tasks are the same as in your R handout, with the same numbers (R 2.1, R 2.2, …) and the same words. Your tier is R 2.6: Core, Applied or Challenge, same data, same idea, different depth.
  • Stuck on a tier task? Open its Hint, then try again. The answers are at the end of your R handout (Part 2 of the Week Pack).

R 2.1 · Load and build the table

With your lecturer

NoteYou should see

Rows are the deposit types; column 0 counts the bookings that stayed and column 1 those that cancelled. The last two lines count one row’s cells with sum(): the same numbers table() shows. Divided by all bookings, each cell is a joint probability; the row and column totals are marginal probabilities.

R 2.2 · Conditional shares: condition on the row

With your lecturer

NoteYou should see

Each line is \(P(\text{cancel} \mid \text{deposit type})\): within one row of the table, the cancelled count divided by the row total. Non-refundable bookings cancel far more (99.4%): that is last week’s closing question answered.

R 2.3 · The other way round: condition on the column

With your lecturer

NoteYou should see

Now we condition on the column (the cancelled bookings): of all cancellations, only 32.9% were non-refundable. \(P(A \mid B)\) and \(P(B \mid A)\) are different numbers.

R 2.4 · Independent or not?

On your own · about 6 minutes

NoteChange one thing

Change "City Hotel" to "Resort Hotel" in the is_city <- line, run that line, then run the last two lines again. (The name is_city now holds TRUE for each resort booking: R keeps the name, whatever the test.) Is P(Resort and cancelled) equal to P(Resort) × P(cancelled)? Compare them to 3 decimal places.

NoteYou should see

If hotel and outcome were independent, \(P(\text{cancel} \mid \text{City})\) would equal \(P(\text{cancel})\), and the last two numbers would be equal. They are not.

R 2.5 · Total probability and Bayes’ rule

On your own · about 6 minutes

NoteChange one thing

In the Bayes card, change nr to ref in all three places (ref is TRUE for refundable bookings, from the card above). Do Bayes’ rule and counting agree on P(refundable | cancelled)? Give it to 4 decimal places (it is small).

NoteYou should see

The first number is \(P(\text{cancel})\) rebuilt from the deposit groups. The last two are the same: Bayes’ rule and counting in the table agree.

Commands to know

In scope (you run them in this week’s tasks and sets): table() for counts by two columns (table(hotels$deposit_type, hotels$is_canceled)); sum() on a test to count (sum(hotels$deposit_type == "Non Refund" & hotels$is_canceled == 1)); a count divided by its row total or its column total for a conditional probability; mean(hotels$is_canceled[hotels$hotel == "City Hotel"]) for one group’s share; mean(hotels$hotel == "City Hotel" & hotels$is_canceled == 1) for a joint share. Also in scope: sample() with set.seed() for a simulation (R 2.7).
