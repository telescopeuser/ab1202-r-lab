# AB1202 R Lab

Base R in the browser for **AB1202 Statistics & Analysis**: the weekly lab pages and an R console in one installable web app. It runs R entirely on your own device (webR), works offline once saved, and needs nothing installed from a software site.

**Open it:** https://telescopeuser.github.io/ab1202-r-lab/

RStudio on your laptop is the main way to do the course's R work; this app is the alternative and gives the same results.
