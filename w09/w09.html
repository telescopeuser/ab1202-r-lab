How to use this lab

RStudio is the main way to do the lab (the R handout in your Week Pack and the R Recipes file). This page is the alternative when RStudio is not available: it runs R in your browser (webR), with nothing to install. The code is the same, starting with the same first line, hotels <- read.csv("hotels.csv").

  • Press Run Code on each cell. Change the code and run it again; you cannot break anything.
  • Step 1 is always the same line: hotels <- read.csv("hotels.csv"). On this page it runs by itself when the page opens; wait for the first cell to show the size of the data.

Core. City against resort rates with t.test(a, b): 50 from each hotel (R 9.2), then 200 (R 9.3). For each: \(t\), the p-value, the 95% interval, and your decision.

TipHint

the interval is t.test(a, b)$conf.int. If it includes 0, the test does not reject at 5%.

NoteAnswer (try first)

Core. 50 each: \(t\) = 1.31, p = 0.193, CI -8.14 to 39.59: do not reject. 200 each: \(t\) = 3.94, p < 0.0001, CI 9.41 to 28.16: reject. The whole file’s gap is 10.10 euros: the small samples made a Type II error.

set.seed(9)
a <- sample(city, 50)
b <- sample(resort, 50)
t.test(a, b)
set.seed(9)
a200 <- sample(city, 200)
b200 <- sample(resort, 200)
t.test(a200, b200)

Applied. Test whether city and resort bookings cancel at different rates (R 9.4), by hand: pool the shares, find \(z\) and the two-sided p-value, and compare with prop.test().

TipHint

pool <- (sum(x1) + sum(x2)) / 400; z <- (mean(x1) - mean(x2)) / sqrt(pool * (1 - pool) * (1/200 + 1/200)); 2 * (1 - pnorm(abs(z))).

NoteAnswer (try first)

Applied. 0.510 against 0.305; pooled 0.407; \(z\) = 4.17; p < 0.0001, the same as prop.test(..., correct = FALSE). Reject: city bookings cancel more (observational data: not a cause).

# ... as above, with 1 / 200 + 1 / 200
c(z = z, p = 2 * (1 - pnorm(abs(z))))
prop.test(c(sum(x1), sum(x2)), c(200, 200), correct = FALSE)$p.value   # the same p-value

Challenge. p-hacking by simulation: in 500 batches of 20 tests on pure noise (set.seed(9)), how often is at least one “significant” at 5%? And at the Bonferroni level \(0.05/20\)?

TipHint

copy R 9.7 and change 2000 to 500 (in both places). Inside the outer loop, make the 20 p-values; any(p < 0.05) and any(p < 0.05 / 20) record a false discovery; mean() of each list gives the shares.

NoteAnswer (try first)

Challenge. About 0.62 at 5% (theory 0.642) and 0.03 with Bonferroni.

Stretch (any tier, if you finish early). With 10 tests: the Bonferroni level, and the chance of at least one false alarm without it (1 - 0.95^10).

NoteAnswer (try first)

Stretch. Bonferroni: 0.005 for each test. Without it: 0.401.

Commands to know

These can be assessed in the quiz: t.test(x, y) and t.test(y ~ group, data = d) for two means, prop.test(c(x1, x2), c(n1, n2), correct = FALSE) for two shares, $p.value and $conf.int, and 1 - 0.95^m for many tests. Remember: report the size of the gap with its interval; a p-value is not the chance that \(H_0\) is true.
