NoteAnswer (try first)

Core. \(p = 0.281\), \(R = \text{€}443.78\); model €319.16; data €295.15. The resort bookings that cancelled were bigger (€529.28 against €410.40), so one average price makes the model too high.

Applied. Find the SD of one resort booking’s revenue (two-value model), then the expected total and SD for 20 resort bookings. Compare the square root of 20 and 20 times the SD.

TipHint

as in R 4.3 and R 4.5, with the resort’s p_r and R_r.

NoteAnswer (try first)

Applied. SD of one: €199.43. Twenty: mean €6,383.26, SD €891.89 (20 times the SD would be €3,988.64).

resort <- hotels[hotels$hotel == "Resort Hotel", ]
p_r <- mean(resort$is_canceled)
R_r <- mean(resort$revenue)
x <- c(R_r, 0)
px <- c(1 - p_r, p_r)
EX <- sum(x * px)
SD <- sqrt(sum((x - EX)^2 * px))
20 * EX
sqrt(20) * SD

Challenge. A deposit at the resort. For a 20% and a 30% deposit, find the gain per booking and the break-even walk-away share. Which would you test first?

TipHint

with a deposit share deposit, a cancelled booking brings in deposit * R_r; break-even is 1 - EX / EXd.

NoteAnswer (try first)

Challenge. 20%: gain €24.92, break-even 0.072. 30%: gain €37.39, break-even 0.105. A larger deposit can afford more walk-aways but is likely to cause more: test the smaller one first, on part of the bookings, and measure.

resort <- hotels[hotels$hotel == "Resort Hotel", ]
p_r <- mean(resort$is_canceled)
R_r <- mean(resort$revenue)
EX <- (1 - p_r) * R_r
for (deposit in c(0.2, 0.3)) {
  EXd <- (1 - p_r) * R_r + p_r * deposit * R_r
  print(c(deposit = deposit, gain = EXd - EX, breakeven = 1 - EX / EXd))
}
