How to use this lab

RStudio is the main way to do the lab (the R handout in your Week Pack and the R Recipes file). This page is the alternative when RStudio is not available: it runs R in your browser (webR), with nothing to install. The code is the same, starting with the same first line, hotels <- read.csv("hotels.csv").

  • Press Run Code on each cell. Change the code and run it again; you cannot break anything.
  • Step 1 is always the same line: hotels <- read.csv("hotels.csv"). On this page it runs by itself when the page opens; wait for the first cell to show the size of the data.
  • The tasks are the same as in your R handout, with the same numbers (R 1.1, R 1.2, …) and the same words. Your tier is R 1.7: Core, Applied or Challenge, same data, same idea, different depth.
  • Stuck on a tier task? Open its Hint; then try again before you open its Answer.

If something goes wrong. The first visit downloads R into your browser (about a minute on campus Wi-Fi; faster afterwards). If a cell says Loading for more than two minutes, reload the page. If you see object 'hotels' not found, run the first cell again. Red text is an R error message, not a broken page: check spelling, capitals and brackets. Use Chrome, Edge, Firefox or Safari on a laptop; phones work but are cramped.

Challenge. Which arrival month has the highest cancellation share? Is the gap between the city and resort hotels the same every year?

TipHint

loop over the months: for (i in 1:12), keeping the rows where hotels$arrival_date_month == month.name[i] (month.name is R’s built-in list of month names). Then loop over the years with for (y in 2015:2017), comparing the two hotels inside each year.

NoteAnswer (try first)

Challenge. Highest: June (0.418). City minus resort by year: 2015 0.189; 2016 0.139; 2017 0.118. The city hotel cancels more every year, by a different margin.

share <- numeric(12)
for (i in 1:12) {
  in_month <- hotels$arrival_date_month == month.name[i]
  share[i] <- mean(hotels$is_canceled[in_month])
}
names(share) <- month.name
sort(share)
for (y in 2015:2017) {
  city_y   <- hotels$hotel == "City Hotel" & hotels$arrival_date_year == y
  resort_y <- hotels$hotel == "Resort Hotel" & hotels$arrival_date_year == y
  gap <- mean(hotels$is_canceled[city_y]) - mean(hotels$is_canceled[resort_y])
  print(paste(y, ": city minus resort =", round(gap, 3)))
}
